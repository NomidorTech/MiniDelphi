Rebrand: MiniDelphi -> Pythia

A real name for a real tool. No more "toy" anything.

Pythia is the priestess at the Oracle of Delphi. Where the Oracle
spoke through her, Pascal speaks through Pythia. Same engine, same
Form Builder, same six-tab IDE -- new name, fresh identity.

Sweep across all source files and documentation:
  * Title bars, About dialog, README, Programmer's Guide
  * Project renamed:  MiniDelphi.dpr -> Pythia.dpr
  * Settings file:  MiniDelphi.settings.ini -> Pythia.settings.ini
  * Version bumped to 1.2
  * Tagline:  "Where Pascal begins."
  * Every occurrence of the word "toy" eliminated

File extensions intentionally kept (.mdp, .mdproj, .mdfrm) so
existing saved projects continue to load.

GitHub repo renamed from MiniDelphi to pythia -- old URLs redirect.
